# Trade Ledger

面向电脑城商家、电脑维修 / 装机商家、IT 渠道商家和同行商家的生意往来账 Web App。

> 记录“生意发生了什么”，而不仅仅是“钱进来了还是出去了”。

## 产品定位

Trade Ledger 用于记录商家与客户、供应商、同行及个人之间发生的销售、采购、服务、调货等业务，并持续跟踪由业务产生的应收、应付、收款、付款、部分结算、抵扣和最终结清。

核心业务链路：

```text
往来对象
  ↓
业务往来
  ↓
形成应收 / 应付
  ↓
后续结算
  ↓
部分结算 / 全部结算
  ↓
形成完整、可追溯的往来流水
```

## V1 核心能力

- 往来对象管理：同一对象可同时存在应收和应付关系
- 业务往来：销售、服务、采购、调货、串货
- 多商品 / 服务明细
- 应收、应付及剩余金额自动计算
- 收款、付款及部分结算
- 基础应收 / 应付抵扣
- 往来对象完整时间线
- 待收款、待付款及近期往来概览
- 移动端优先的快速新增往来流程

## 核心原则

1. 原始业务与结算记录分离，结算不会覆盖原始业务。
2. 一笔业务可以发生多次结算。
3. 同一往来对象可以同时存在应收和应付。
4. 每笔余额都应能够追溯到原始业务及后续结算记录。
5. 金额计算必须保持精确，避免浮点精度误差。

## V1 暂不重点实现

完整进销存、库存管理、复杂财务会计、发票与税务、多门店、多员工权限、原生移动端以及 AI 自动记账等能力暂不属于 V1 核心范围。
